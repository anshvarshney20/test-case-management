# User Guide by Role

## Admin

1. Sign in with `admin@demo.com` / `Admin@123`.
2. Open **Users** to create accounts and change roles.
3. Create/edit/delete **Projects** and manage all test data.
4. Execute tests, view analytics, manage defects.

## Test Lead

1. Sign in with `lead@demo.com` / `Lead@123`.
2. Create and maintain projects you belong to.
3. Author test cases and suites; assign cases to testers via case edit / bulk suite assign.
4. Execute tests and review dashboard trends.

## Tester

1. Sign in with `tester@demo.com` / `Tester@123`.
2. Browse assigned cases under **Test Cases**.
3. Open a case → **Execute** → choose Pass/Fail/Blocked/Skipped.
4. On Fail, optionally create a defect automatically.
5. Run an entire suite from **Suites → suite detail → Execute suite**.

## Read-Only

1. Sign in with `readonly@demo.com` / `Read@123`.
2. View projects, cases, suites, executions, defects, and the dashboard.
3. Create/edit/execute controls are hidden or disabled.

## Tips

- Use the sidebar **Project** picker to switch context.
- Dashboard shows cache hit/miss for analytics.
- Toggle **Dark mode** from the sidebar.
- Export cases as CSV from the Test Cases page.
